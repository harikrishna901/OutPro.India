A modern digital platform website designed for **Outpro.India**, focused on presenting digital services, projects, and business solutions through a clean and responsive user interface.

## 📌 About the Project

Outpro.India is a modern business website built to represent a digital innovation company and showcase its services, portfolio, and client-focused approach.

The website features a dark, modern interface with orange accent colors, smooth navigation, responsive sections, and clear call-to-action elements.

## ✨ Features

- 🏠 Modern landing page
- 📱 Responsive website design
- 🧭 Navigation bar with:
  - Home
  - About
  - Services
  - Portfolio
  - Testimonials
- 🚀 Call-to-action sections
- 💼 Services showcase
- 📂 Portfolio section
- 💬 Testimonials section
- 🎨 Modern dark-themed UI
- 🌗 Theme toggle
- 📊 Company/project statistics
- 📱 Mobile-friendly layout
